# Shri Malikarjun Hardware & Paints

A professional, industrial retail website for Shri Malikarjun Hardware & Paints, Canacona, Goa.

The visual direction is original but inspired by the high-contrast, trade-focused language common to professional tool/jobsite brands: bold typography, black/white/grey foundations, orange action colour, strong product grids and trade-oriented navigation.

The site does not reproduce DEWALT branding, logos, copy or proprietary assets.

- `public/sm-hero.png` — supplied/generated hero photograph
